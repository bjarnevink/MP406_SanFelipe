## Use the calculations spreadsheet after extracting flood data from the SFINCS model.

### How to use the calculations spreadsheets
  - Fill in the cluster properties
  - [optional] Adjust parameters such as material factor, height factor, time factor, protection factor.
  - [optional] Adjust damage score formulation
  - The Excel sheet calculates normalised comparative damage scores for the building typologies in each cluster on a scale from 0 to 1.
  - Export an Excel sheets for visualisation of the result for a specific cluster.
